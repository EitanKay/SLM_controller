# Test patterns

This folder is for small, committed, known-good patterns.

Suggested files:

| File | Purpose |
|---|---|
| `flat_black.bmp` | blank/flat sanity check |
| `flat_midgray.bmp` | intermediate gray sanity check |
| `linear_ramp_x.bmp` | horizontal beam steering |
| `linear_ramp_y.bmp` | vertical beam steering |
| `vortex_l1_with_carrier.bmp` | first vortex test |
| `hg10_reference.bmp` | simple HG test |

For Meadowlark DVI 16-bit BMPs, use the project generator/packing logic rather than hand-editing RGB channels.
